# Mini Bank System

A simple command-line banking system built with Python as a practice project.

## Features

* Create a new bank account
* Show all existing accounts
* Deposit money
* Withdraw money with balance validation
* Transfer money between accounts
* View transaction history
* Save account data to a JSON file
* Load saved account data when the program starts
* Handle missing or invalid JSON data

## Concepts Practiced

This project was built to practice:

* Python functions
* Dictionaries and lists
* Loops and conditional statements
* Input validation
* Exception handling
* Working with JSON files
* Reading and writing files
* Managing program state
* Basic data persistence

## How to Run

1. Make sure Python is installed.
2. Download or clone the repository.
3. Run the Python file:

```bash
python "mini bank system.py"
```

4. Follow the menu displayed in the terminal.

## Menu

```text
===== Bank System =====
1. Create account
2. Show account
3. Deposit money
4. Withdraw money
5. Transfer money
6. Transaction history
7. Save data
8. Exit
```

This project is part of my Python practice journey. The goal was to move beyond basic exercises and build a small functional system that manages data, performs transactions, validates user input, and stores information between program sessions.
